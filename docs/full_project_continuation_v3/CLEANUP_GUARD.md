# 清理旧文件前的边界

本包不会删除文件。preclean_inventory.py只读取Git路径状态，不读取内容、不备份、不判可以删除。

最新continuation的源码虽已公开，但LOCAL_ONLY_MANIFEST_R2仍有只存本地的大型MPH、依赖/运行树、私有SQLite和完整raw证据。清空旧目录之前，应单独保留不可重建科学数据和未保存模型，核对备份字节；网络和Git源码不能恢复未提交内容。

可以重下载的固定依赖、新生成测试模型、旧历史native证据必须分别分类。新模型有新SHA与新run，不代表原Activity020已完成。旧job库不存在不能伪造恢复。

保留COMSOL安装、合法许可证和登录凭据。不把它们上传公共仓库/打入包；不自动拷贝旧token/PID/回执到新环境。建议先在新目录恢复并核对源码，再清理确认可重建的旧项目数据。
