# 可选实现路线（不是新增required）

## 最短真实闭环
先复用W13参数设置、W16求解、W17读值以及W19 job。如果已有执行recipe，直接接一层case orchestrator；不要求引入新调度/优化库。
长任务嵌套执行时不能在持有同Server队列锁的handler中再次同步排队自己；复用内部服务/witness或在控制层编排子步骤。所有实际子步骤保留原模型身份与权限。

## 一个可覆盖扫描/优化/阶段传递的小型基准建议
以下是建议，不是历史已执行数据，更不替换冻结W20基准。可采用已有经过验证的其他小模型。
L=0.05m，Tb=300K，A=10K。初温Tb+A*sin(pi*x/L)，两端Tb，侧面绝热，常数alpha=k/rhoCp。解析解Tb+A*sin(pi*x/L)*exp(-pi²*alpha*t/L²)。
可复用当前demo的参数范围k=[380,400] W/(m K)、rhoCp=[3.4e6,3.8e6] J/(m³ K)，时间[0,.5,1,1.5,2]s；采样x=L/4,L/2,3L/4（不是旧公式里超出域的0.25/0.5/0.75m）。实际单位、材料映射、场/数据集从引擎回读，参考由独立公式计算。仅公式的相等不是引擎验收。
有限优化可以在这个范围内最小化t=2s中点偏离304K的误差，附一个真实可检的温度约束和≤9次候选预算；具体约束/容差在运行前固定，可选择更合适的既有夹具。cache复用不重复solve，但必须证明同一输入/解/版本。
阶段1求到t=2，阶段2从其非均匀T场继续；读取阶段2初值多个内部点，对比源末态，续算对比直接从0算到总时刻的参考。保持同一模型网格时可使用COMSOL存储solution作为初值，不一定导出整场再插值；但必须验证实际设置和初值，不只复制字典。

## 官方API线索（下轮核实实际6.3/6.4）
COMSOL 6.4 Parametric Sweep API提供Study的Parametric节点以及pname/plistarr/punit/sweeptype。可以用此原生路径，也可用受管串行独立case；要保留正确index而不把循环位置当引擎inner。
Time Dependent Study具有初始化solution选择设置，具体属性和allowlist以目标版本文档/本机反射实测为准。原生Parametric/Study写法不能凭记忆或只看6.4推广6.3。
来源URL见SOURCE_MAP.json，官方接口可用不等于当前实例许可/模块/队列集成已通过。
