## funcs 缺口修复（唯一生产 diff，9 行含注释）

- 现象：_g3_common.FUNCTION_TYPE_PROPERTIES 的 Interpolation 写允许表不含 funcs，而同一包内三处按 6.4 事实使用它：_g3_w13._FUNCTION_LAYOUT_PROPERTIES（function.data_import 的 layout 词表明确列出 funcs）、模块 docstring（data_import 路线 set('filename'/'struct'/'nargs'/'dseparator'/'funcs'/...)）、data_import 读回行（property_read_rows(..., funcs, filecolumns, fileheaders)）。探针实测：layout 携带 funcs 时写入在 definition_properties 处被拒（INVALID_REQUEST layout/units has unsupported fields: ['funcs']），多维 spreadsheet 插值布局因此无法经 function.data_import 配置。
- 文档依据（本机安装 COMSOL 6.4 帮助，非样例硬编码）：Programming Reference 6.4 Supported Functions and Settings（com.comsol.help.comsol/comsol_api_fileformats.53.17.html）明确列出 Interpolation 的设置 funcs（GUI label Functions，value type StringMatrix，Feature=Interpolation）。model.func() 的短属性表（Table 2-86）不含 funcs，但同一手册文件格式章含它；仓库 W22 原生时代夹具 science_recipes/java/W22Fixture.java 使用 model.func(fn).set("funcs",new String[][]{{fn,"1"}})（历史夹具，一致性佐证，不是本次原生证据）。
- 修复：允许表加入 funcs 并注释依据。未放宽任何门：写仍先查引擎自身 getValueType/hasProperty（新测试 5 钉住：引擎声明 StringMatrix 时标量 funcs 仍被 PROPERTY_TYPE_MISMATCH 在首次写前拒绝且 importData 未被调用）；build 不携带该属性时 API_UNSUPPORTED 行为不变。
