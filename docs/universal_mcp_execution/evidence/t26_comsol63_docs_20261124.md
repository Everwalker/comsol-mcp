# T26 COMSOL 6.3 and 6.4 documentation comparison

The checked official COMSOL 6.3 and 6.4 help pages agree on the following limited points: a Solution dataset may select a component or geometry, with the first available item used as the documented default where applicable; EvalGlobal supports a dataset binding; ModelNodeList and GeomList inherit ModelEntityList, whose tags method returns a string array; and PropFeature.properties returns a string array of property names.
