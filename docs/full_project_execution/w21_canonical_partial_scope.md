# W21 canonical route scope

This implementation changes the `solver.solution_transfer` and `experiment.run` canonical routes while preserving the approved `stage.state_transfer` and `optimization.bounded_run` extensions. The canonical route correction is a software implementation result; it is not native COMSOL acceptance and does not close T021/T047.

The frozen contract at `contract/00_FULL_SPEC.md:278` requires source solution/dataset, time and parameter indices, variable mapping, geometry framework, interpolation, and conservation error. The current transfer adapter is deliberately `PARTIAL`: it configures one exact source solution selection using the `Variables` selector and reads the selector back. It permits either one exact outer/inner pair or one unit-bearing time Quantity whose value and unit match a complete `SolutionInfo` pair. An optional source solution tag must match the dataset-bound solution. It issues no solve.

Nonempty variable mappings are refused because the current adapter neither proves the requested source/target variables nor applies a variable selector. Frequency and arbitrary parameter selectors, geometry-frame conversion, interpolation, conservation-error evaluation, same-mesh claims, and history-continuity guarantees are unsupported and refused. The response reports `coverage_status=PARTIAL`, `verification.status=CONFIGURED_ONLY`, `mesh_compatibility=UNVERIFIED`, `state_continuity=NOT_RUN`, and `history_preserved=false`. A configured initial-value selector does not prove that the next solve preserves history.

The experiment adapter requires a durable `experiment.design` record and reuses the bounded W21 case executor. It currently supports only the validated Cartesian-grid design profile, project/ModelRef/revision binding, and lowering a predeclared resource budget. Each supplied resource limit and timeout is validated independently against the frozen budget before combining them. Budget exhaustion returns `PARTIAL/BUDGET_EXHAUSTED`; unknown or failed cases stop further dispatch and retain the single run claim.

The current software regression is recorded in `evidence/luna_w21_canonical/run_20260926T103600Z_r2/pytest.log` and `junit.xml` (64 passed); `py_compile.log` records syntax compilation. These tests do not establish cross-version API behavior or native COMSOL execution. The action coverage and task state remain partial; all target acceptance cells remain unassessed.
