# W22 六项固定交付

这是对原W22/T016/T045的执行展开，不是重开W20/W21。两版本分别验证；已有相关正确证据可复用，但本轮领域链不能由旧铜块基准替代。

## D1 参数化小环阵列与静态二维热源
原要求：T016/T045。记录发光单元位置/归属/数量/掩码、功率、L和核函数；生成或导入二维Q(x,y)，保留同半径角向差异，单位/哈希/外推可回查。

## D2 真实材料、散热与热预算
原要求：T045。绑定W/m²边界热流（或明确W/m³来源），求解实际材料/散热模型；独立复算输入、截获、吸收、边界输出及必要储能，ROI指标可重建。

## D3 距离扫描与环/组功率有限优化
原要求：T045。至少三个明确L候选及受预算的功率搜索，经现有生产引擎取得实际温度与ROI指标；源变化使缓存失效，同源重复可复用；不宣称全局最优。

## D4 候选复算与不可行诚实性
原要求：T045。独立重算返回可行候选，约束与功率预算成立；含至少一个由保守功率上界即可证明不可能的目标；预算未找到与数学不可行分开。

## D5 原生图、数据、模型与重开
原要求：T016/T045。COMSOL实际源/温度图和数据绑定同一case/L/功率/解；保存同版本MPH与外部源，干净路径新Worker重开可回读，不要求图字节完全一致。

## D6 同源双版本与独立审查
原要求：W22阶段交付。Windows6.3/6.4分别通过D1–D5；主Agent开发、独立Reviewer按同一冻结要求复测；受影响回归，范围和外部物理未验证项明确；完成停止W22。

数值容差、ROI、核函数和预算在首次科学运行前由主Agent提出、Reviewer一次冻结到benchmark_spec，不在结果出来后放宽。不是新增更多原生平台或物理场。缺许可/原始数据如实记录，未执行不得PASS。所有交付已满足、独立审查完成且无A1/A2时必须批准，即使待办非空。
