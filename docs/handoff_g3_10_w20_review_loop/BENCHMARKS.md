# 冻结基准建议（本轮待执行定义，不是已取得结果）

本文件保留已有测试的主要几何/物性，独立Reviewer在开始时核对与原要求一致并冻结版本/哈希。实际温度、功率、误差、网格和耗时必须由运行取得；参考可计算，观测不可预填。

## B1 稳态铜块
L=0.05m，A=0.02×0.01m²，k=400 W/(m K)，端面300K/350K，侧面绝热。T(x)=300+50x/L；点0.0125/0.025/0.0375m对应312.5/325/337.5K，温度误差≤0.1K。
q=-k grad(T)；两端按各自向外法向积分，符号相反、各自幅值80W。幅值相对误差≤1%，净功率残差需声明尺度且来自两个独立测量，不能把同一值复制两次。

## B2 正弦扩散与9个存储点
L=1m，截面0.1×0.1m²（可用等价1D，但必须明确验证范围），rho=Cp=k=1对应SI单位，alpha=1m²/s。两端300K，初始300+10sin(pi x/L)K，侧面绝热、无体热源。
T(x,t)=300+10sin(pi x/L)exp(-pi²alpha t/L²)。x∈{0.25,0.5,0.75}m、t∈{0.01,0.03,0.1}s，9点误差≤0.1K；这些必须对应实际存储/明示插值解，不能按数组位置猜。
热能相对300K的解析值 E=rho Cp A·20L/pi·exp(-pi²alpha t/L²)；dE/dt=-(pi²alpha/L²)E。实际E、两端通量在同一时刻/定义下比较；差分误差和物理符号明确。
