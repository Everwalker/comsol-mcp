# 冻结参考（待执行，不是观测）

## 稳态一维导热的三维挤出模型
L=0.05 m；A=0.02×0.01 m²；k=400 W/(m K)；T(0)=300 K；T(L)=350 K；侧面绝热。
T(x)=300+50x/L。Q的幅值=k A (350-300)/L=80 W。定义q=-k grad(T)，用实际外法向分别积分两端通量，符号应相反；不要把abs逐项后相减掩盖符号问题。
内部x=[0.0125,0.025,0.0375] m参考T=[312.5,325,337.5] K；默认本轮温差绝对误差≤0.1 K、端面功率幅值相对误差≤1%。所有实际读数独立采集。

## 正弦扩散
L=1 m；alpha=1 m²/s；两端300 K；T(x,0)=300+10sin(pi x/L) K。
T(x,t)=300+10sin(pi x/L) exp(-pi² alpha t/L²)。3D挤出可选截面0.1×0.1 m²，侧面绝热；k=rho=Cp=1（匹配单位）是数值测试材料，不是工程材料推荐。
x=[0.25,0.5,0.75] m，t=[0.01,0.03,0.1] s，误差≤0.1 K，实际时间来自存储解元数据。
温度高于300K的内部能量E_excess=rho Cp A (20L/pi) exp(-pi²alpha t/L²)。dE/dt=-(pi²alpha/L²)E_excess，与端面向外通量总和满足dE/dt + Q_out = 0（无源）。以积分场观测或明确时间差分估计储能，误差与差分步长一起报告。
这只是本轮独立解析基准，不构成用户实际光纤/VCSEL/固化模型的物理验证。
