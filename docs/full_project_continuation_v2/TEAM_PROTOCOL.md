# 主Agent直接开发；最终独立Reviewer统一验收

开发期主Agent负责全部实现、focused tests、真实最小链路、复现和正常源码管理。不强制独立Developer，也不要求每个函数/候选单独签字。可为特定高风险问题咨询Reviewer，不把咨询变成新阶段停止点。

统一审查在全量候选准备好或仅剩不可解决外部条件时触发。Host实际创建独立上下文；记录真实会话与候选源，不硬编码/root/reviewer。Reviewer不修改生产源，可以使用独立只读分析、独立测试脚本和任务所有模型复测。

输入是原要求＋scope decision＋候选代码及变更＋原始结果索引＋实际安装构件＋剩余范围，而不只是主Agent总结。文件哈希、测试数量、目录存在、JVM编译或生成JSON都不等于科学/原生验证。

Reviewer只可用原要求和具体严重风险阻断；每项写明原条目、候选身份、复现输入、实际/期望、证据与影响。风格、追加模块、新优化算法等建议进入待办，不扩大终点。多个数据来源按准确范围继承，不能全盘复测也不能无依据豁免。

输出APPROVED / CHANGES_REQUIRED / BLOCKED / SCOPED_REVIEW_WITH_BLOCKERS。后两者不等于全项目接受。主Agent不得修改Reviewer结论；修复后冻结新候选，复测受影响部分。批准只对被审源有效，文档附录等非执行变化可明确用hash桥接而无需重跑全部科学计算。

缺独立能力时继续开发/自测并标REVIEW_BLOCKED；不能自我换角色批准。无自动N轮通过，但也不因非阻断待办而无限拒签。
