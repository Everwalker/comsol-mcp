# 清理前保护：本包不自动删除任何文件

当前cutoff066明确记录九处科学工作树修改受保护，但本次未获取其未提交字节。公开GitHub只能恢复已提交内容。**不要在确认副本和hash之前删除旧科学工作目录、/private/tmp或外部SSD项目目录。**

可选只读盘点：
```
python tools/preclean_inventory.py --repo <旧仓库路径> --output <新的本地报告路径>
```
只列Git HEAD、dirty/untracked/ignored路径和空间信息；不读取文件内容、不拷贝秘密、不作备份、不杀进程。报告可能包含私有文件名，仅在本机保存，不提交公共仓库。

需要保存的候选源/MPH/外部数据/关键非公开回执：按明确文件清单另行备份到安全目录并校验字节；不要无差别归档整个home、控制token、SSH或Git所有refs。Git bundle只包含所选可达对象，不包含未提交工作树或存储在外部的模型。基准可再生不是用户唯一实验数据可再生。

已清理导致文件不存在：标LOCAL_ONLY_CONTENT_UNAVAILABLE，不伪称恢复了它们；若公开源有构建器，在新活动/新SHA下重建并验证。不应让可独立实现的软件任务一直等待不可恢复的历史文件。

工作区规划建议：源与新venv/编译缓存、scratch、公开科学产物、私有control互相分开。临时目录指向当前确有权限且空间充足的本地盘，用子进程环境变量，不改全机设置。清理仅限本轮已退出且确属临时的对象；已冻结源码/原始失败/UNKNOWN需要的数据保持。
