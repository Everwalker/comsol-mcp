# W22 固定终点与阻断政策
继承上一轮 Closure Mode。W20/W21 批准限定范围有效，非相关改动不触发重新审查27个目标或全部历史测试。

本轮只按 frozen/W22_CONTRACT.md 的六项交付。阻断项必须是：
A1：能引用本轮原T016/T045/W22交付的明确未实现/未测试/失败要求；或
A2：有直接代码/复现证据的严重错误：错模型/错解/错热源、数值伪成功、破坏用户模型或权限/进程越权。
不得仅用P0/P1标签、想象中的风险、代码风格或“还有优化空间”阻止毕业。新增算法、额外GUI/OS/所有商业模块/大规模性能进入DEFERRED_BACKLOG。合理物理不确定性必须报告，但没有真实器件校准数据不阻塞合成领域验收。

每个阻断只列原要求、具体证据、最小修复和复测。修复影响旧W21才做相应回归；不把旧未访问环境当新障碍。独立Reviewer可设计反例，但不能加新领域功能或数值目标。
所有冻结交付通过且无A1/A2，必须批准 W22_SCOPED_APPROVED，即使待办非空；批准后停止，不自动W23。
