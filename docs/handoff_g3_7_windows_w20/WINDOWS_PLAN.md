## 六条数据绑定
每个数值/图像/报告绑定：source identity、runtime version/build、model_ref/generation/revision、dataset/solution、outer/inner与实际参数/时间、原始产物哈希。
W20 不引入第二套求值器/ArtifactStore/job queue；复用 W17/W18/W19 公共服务。
需要额外计算/临时节点/隔离副本时显式标记副作用、请求权限、使用原作业与恢复机制。
