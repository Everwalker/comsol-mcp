## 2. 恢复

`python3 tools/bootstrap.py --method auto` 默认优先 Git、否则 HTTPS ZIP。它在新的临时目录取固定 SHA，检查 Git tree 和逐文件 Git blob/sha256，成功后发布为新 `repository/`。不会 checkout main 的浮动版本，不会 reset/clean 旧目录。安全拒绝 archive traversal、特殊文件、错误 tree；历史符号链接以普通文本保留，不连接已删除旧目录。大归档预算不足必须报告或显式调整，不得漏取证据后称完整恢复。

新回执位于 `repository/docs/handoff_g3_4/RESTORE_RECEIPT.json`。原先根目录回执属于历史，被保留。

Git 路径产生以真实公开提交为父的开发分支，符号链接使用 core.symlinks=false。若无 Git，可先用源码目录完成软件工作；发布时从同一 PIN 建立新的 Git 工作目录，经文件清单迁移本轮补丁和新证据。不得 git init 造一个无关根提交后强推。历史符号链接测试需要在测试临时目录单独创建合成链接，不能启用指向旧机私有路径的源证据链接。

## 3. 重新建环境

读取恢复源码中的 pyproject、当前机器锁/约束及最新 source-outside wheel 验证命令。不要用旧 DEPENDENCIES 的 VERIFIED 标记自动认定当前环境已认证。检测当前解释器、OS、架构与 JDK；采用当前可获取且能验证的一致 Python 版本。确切旧版本不可获取时记录差异，建立新 venv 并运行兼容回归，不静默替换成旧实测环境。

依赖下载优先项目认可的官方源。机器可读锁、pip check、实际 freeze、版本与构件哈希纳入新证据；不要复制旧 venv/JDK。编辑安装只用于开发，另需非 editable wheel 安装至独立 venv，并在物理上不同于源码/安装目录的项目路径测试。安装目录只保存程序，项目数据根与控制私有根独立（见 R01/R02）。

恢复器不安装 COMSOL。发现既有合法 COMSOL 6.4 与 JDK11；分别核对实际完整 build、架构、客户端 classpath。不存在时完成软件任务与配套配置模板，实机任务如实 BLOCKED。6.3/Windows 不可访问不阻塞独立 Mac 开发。

## 4. 新运行时与模型

公开记录的旧 PID、端口、凭据路径、Valve 回执只能作历史材料。读取当前运行时拓扑，保护现有用户 Desktop/共享 Server 和未保存模型。使用任务自有隔离实例及本轮实时核验的身份；按照已验证启动程序工作，不重用过期 receipt，也不为了启动绕过访问边界。涉及安装文件/系统防火墙等非项目写入必须遵循已有明确授权范围，否则暂停该动作并说明最小必要人工步骤。

需要服务认证时由本机安全登记；不向聊天/仓库/公共日志输入密码、私钥和 token。缓存关闭不等于撤销 credential；只有已实际检查/处理才能声明撤销。默认不停止共享 Server。

## 5. 删除本地文件的边界

可恢复：固定提交中源码、tests、docs、已提交证据与模型。可重新生成：已提交构建器产生的测试模型、帮助索引、venv。
不可恢复：未提交/ignored 的唯一模型、外部实测数据、Desktop 未保存内容、旧账号状态和私有日志。确需保留其科学价值时，先安全备份；不能声称本包已包含它们。

本轮新的输入 fixture 必须来自包恢复后的源码、已提交原始数据或公开可重新获取的来源。generated Java builder 应由已提交程序生成。若历史检查只有一个散落的私有文件，没有 recipe，先补 recipe 并重跑，不复制历史 PASS。

固定本轮公开提交与 tree，保留新的源码快照/已授权科学产物或可重建 recipe，排除 token、prefs、锁、数据库、临时 venv。扫描当前 tree 和本轮拟公开 commit 对象，不能只检查工作区没有 secret。保留历史未通过事实，用追加 verdict 说明已被哪次运行覆盖。新联网恢复包必须锁定本轮公开来源并在新目录测试。
