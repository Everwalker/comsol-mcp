A group uses sequence3 and receipt-body3, preserving the original per-resource V2 receipt row and Store intent/readback rows. Restore validates the exact source schema/plan/profile/receipt/group and a fresh complete snapshot before authorization and again before each original resource deletion.

A complete group includes one original absent-only provider CREATE, one sublayer CREATE, exactly four package-SID-only BLOCK defaults (CONNECT v4/v6, RECV_ACCEPT v4/v6), and exactly one PERMIT per unique approved profile grant. Filter keys must equal the entire explicit profile filter key set with no duplicate/collision. Each member is a closed object with `schema, group_id, group_sha256, filter_key, provider_key, sublayer_key, action, weight, flags, layer_key, direction, address_family, principal_sid, grant_sha256`. The whole fingerprint includes the host profile SHA, explicit group ID and sorted complete desired members excluding their fingerprint field. No default target values are supplied.

BLOCK has grant SHA null and only the package SID condition. PERMIT binds the exact original grant hash and native role image App-ID, package SID, TCP or UDP, exactly one canonical local and remote IPv4/IPv6 CIDR, and one explicit local and remote port. Zero/multiple selectors, LISTEN/BIND, ICMP, unknown layer, mismatched direction/family/image or omitted fields refuse the whole group before consuming authorization/SDK mutation. Flags exactly persistent (1); action is ordinary default BLOCK or soft PERMIT, with no CLEAR_ACTION_RIGHT, callout or provider context. Weights are explicit uint64; each permit strictly outweighs its same-layer default in the same sublayer. This describes the owned group's intent and readback, not global arbitration against other providers/sublayers/callouts.

The capacity is the original 4096 profile filter keys: 4..4096 filters and 6..4098 total steps, with exact derived `2 + 4 + uniqueApprovedAllows`, not arbitrary widened resource count. Original 8 MiB serialized bounds, finite observer bounds and operation deadline remain. Unsupported byte/time bounds refuse before effect or retain runtime UNKNOWN; this unit does not enlarge them. A 4098 count/shape negative control executes no 4k SDK effects.

Each filter SDK readback checks exact owner marker, keys, explicit action/flags/weight and effective weight, runtime ID, no callout/context, package SID, native App-ID and every condition. The complete actual group snapshot must match all receipt resource hashes. Partial effects, malformed SDK returns, I/O/readback/cleanup failures stop at the first error, retain original cause, journal UNKNOWN/safe_retry=false and never replay. Reverse restore is filter→sublayer→provider only when original receipt/current complete group exact; foreign/changed dependencies remain recovery-required.

Mutation API engine/transaction/FWPM memory/LocalFree SID/SD plus synchronous SDK backing buffers use the original registry, original acquired object/address and captured first SDK closer.
