A private actual preflight root is registered before the first readonly acquisition. It holds the actual original API, existing registry, first SDK functions and first cause in a private in-memory root table, independently of object cycles or whether a caller retains an exception. Initial root registration refuses re-adopting existing resources: the root must precede this original API's first acquisition. An API that completed original cleanup cannot be re-adopted/replayed. No root is reconstructed from JSON, persisted metadata, booleans or caller proof.

OpenProcessToken, ConvertStringSidToSidW, GetSecurityInfo and NtCreateFile register any actual returned output storage even when the SDK raises after writing. The original CloseHandle or LocalFree is captured before the SDK acquisition. BOOL/DWORD/NTSTATUS/LocalFree returns use their actual typed domains. Malformed returns fail closed; invalid pointer/HANDLE storage is retained UNKNOWN and never passed to arbitrary native close/free. Native DWORD/BOOL false and I/O errors cannot return security PASS or continue a provider grant. Failure cleanup attempts each newly acquired original entry once, skips UNKNOWN during automatic unwinding, preserves first cause and leaves the strong root. Explicit private cleanup retries only those exact original entries and original callbacks, performs no path/grant/host operation replay, and reconciles only confirmed terminal ownership.

TokenUser SID points into the original captured token buffer, within its successful returned byte extent and canonical SID header bounds. It is borrowed, retained with that token buffer, and never LocalFree'd. GetSecurityInfo owner/DACL pointers are borrowed from the original descriptor allocation and are never independently freed. LocalFree applies only to registered converted SID/descriptor allocations. The synchronous backing objects are strongly held before validation can fail. The original registry RLock serializes complete readonly verification and original cleanup so live borrowed data cannot be freed by a concurrent cleanup call.

Controller's already-existing sealed pending request root remains earlier than trusted-profile loading/native executor construction. If the constructor fails before returning an executor, the actual original preflight owner is retained through the failure and its module root. The same private reconciliation method accepts the exact owner bound in the original failure chain only after explicit original cleanup is confirmed. It does not alter the consumed sealed request, scoped grant nonce, Store historical UNKNOWN, operation/job identity, `_pending`, policy issuer, public RPC or host apply/restore.

Production-function tests execute the actual double component traversal, native SDK buffer emission/return decoding, HostScopedProvider.load and grant revalidation, existing registry, Controller pending holder, GC and cleanup.
