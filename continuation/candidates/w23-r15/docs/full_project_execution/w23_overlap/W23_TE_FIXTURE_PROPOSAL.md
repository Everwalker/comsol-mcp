## Proposed numerical controls to freeze before solving

These are proposed acceptance tolerances; the owning executor must freeze them with the exact mesh, port normalization and export settings before the first study run, and may tighten them based on the benchmark accuracy target. They must not be relaxed after seeing a result.

| Control | Proposed gate |
| --- | --- |
| Independent mode index | `abs(neff_comsol - 1.540405036791) <= 2e-3` on a coarse mesh and `<= 5e-4` on the refined mesh. |
| Mesh pair | Initial maximum element size no larger than `lambda0/(6*n_core)` (about `0.1615 um`), then halve it; record actual element count and port-edge resolution. |
| Aligned self-overlap | `normalized_overlap >= 0.995` on the initial mesh and `>= 0.999` after refinement; preserve raw complex cross integral and both powers. |
| Integral refinement | Relative change in each independently recomputed input/output power and cross integral no larger than `1e-3` between the registered quadrature refinements. |
| Core-aperture capture | For the registered `x=8 um`, `y=[-0.5,+0.5] um` core-only aperture, compare native signed `W/m` flux, independently recomputed native denominator, and reported `eta_capture` against raw-field Simpson integration at `1e-3`; preserve reverse flux without absolute value or clipping. |
| Upstream power balance | On the frozen upstream guide control volume, use the oriented native fluxes `P_in`, `P_r`, `P_t`, and separately measured side-boundary radiation `P_side,guide`; record `r_guide = P_in - P_r - P_t - P_side,guide` and `epsilon_guide = abs(r_guide)/P_in`. Freeze each plane, normal, direction, and the fixed denominator `P_in`. Provisional target: `epsilon_guide <= 5e-3` initially and `<= 1e-3` after refinement. |
| PML power balance | On a separate PML control volume, use `P_t` entering its upstream face, `P_abs,PML`, `P_exit,PML`, and separately measured PML side leakage `P_side,PML`; record `r_PML = P_t - P_abs,PML - P_exit,PML - P_side,PML` and `epsilon_PML = abs(r_PML)/P_t`. Freeze every face/normal and the fixed denominator `P_t`. Do not add `P_t` and its downstream absorption to the same balance. Use the same provisional residual limits as the upstream balance. |
| Phase control | First, multiply the exported signal by a known global complex phase and verify in independent recomputation that the complex overlap amplitude rotates while powers and `normalized_overlap` remain unchanged within `1e-8`. Separately, vary the native input Port excitation phase, solve each frozen phase case, and compare the resulting native raw complex fields and overlap phase while checking that physical powers remain invariant. The software-only phase control cannot replace this native solve-and-field gate. |

The final native route must retain unnormalized raw complex E/H data, coordinates, selected port mode/eigenvalue, mode basis, plane and normal, frequency, solution/dataset identity, geometry revision, integration units, solver provenance, and the exact native selection readbacks. Compare COMSOL `IntLine` results to an independent quadrature of the exported complex fields; self-overlap alone is not a convergence or physical validation.

The candidate08 route computes `eta_mode` and `eta_capture` only when native references, selections, and positive incoming power are fully bound. The planar capture ratio is a limited mechanism check, not final assembly capture acceptance. Preserve signed raw powers and overlap; reject nonpositive/near-zero normalization powers and never clip results into range.
