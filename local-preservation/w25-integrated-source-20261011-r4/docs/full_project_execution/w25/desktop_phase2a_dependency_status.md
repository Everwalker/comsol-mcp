# W25 Phase2a dependency and truthful status software unit (historical stage)

The opt-in desktop extra supplies psutil and macOS PyObjC ApplicationServices, Quartz and Cocoa/Foundation providers with darwin markers. Ordinary mcp/MPh/JPype1 dependencies and dev pytest remain unchanged. Packaging declarations are not installed runtime proof; resolved binary wheel pins/hashes and actual caller imports need a separately authorized new task-owned observer runtime.

Default MacOSMetadataAdapter.status is lazy until called. It checks dependency/API availability before a nonprompt AXIsProcessTrusted query. Missing providers/APIs or API exceptions return permission UNKNOWN and metadata UNAVAILABLE with the actual exception stage/type/message. A successfully returned false bit is BLOCKED_PERMISSION; true is only this product caller's permission. Missing Quartz/psutil/Foundation cannot produce metadata AVAILABLE. Status does not enumerate windows, read AX trees, capture pixels, prompt, launch, send input or query screen-capture permission. Controls remain unsupported and no observed COMSOL selector/profile is added.

Software tests use injected framework protocol fixtures only. Eight native actions/T004/T023/T051/T052/T054, shared binding/standalone dirty-preserving save migration/Shell/cancel remain open. Private load and expected mutation were design pending in this phase-specific unit. The later Phase2b candidate added a software-only managed-session saved-copy load callback; it did not add native Desktop load, expected-mutation acceptance, or GUI binding. COMSOL 6.4 documents Java Shell only in Windows Desktop; this phase establishes no equivalent macOS route or visible-window/model/endpoint/dirty-state/save-copy observation. The macOS facts remain `UNOBSERVED` and controls refuse without supported evidence. Phase1/live repository and Native34/Test38 were protected.
